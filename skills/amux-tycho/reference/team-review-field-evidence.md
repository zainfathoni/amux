## Exact evidence for one #328 field run

Record all items against the same receipt:

1. Native Amp coordinator/child identity and independent first-pass completion before Tycho input.
2. Exact owner-authorized existing or prepared route; prepared-route evidence proves no provider execution before adjacent identity revalidation.
3. Pre-Tycho artifact mode, repository, canonical paths, full head/tree, cleanliness, frozen task bytes, and recomputed digest. For `immutable-remote`, include the frozen source identity and every comparison attachment's canonical path and full HEAD/tree.
4. Immutable `created` receipt with `report_only` before execution.
5. Separate-process recovery is either performed or already proven for this install and revalidated by `show`.
6. Exactly one producer/session/run/task-bound `valid_report`; logs and exit codes do not count.
7. Post-Tycho/pre-consume artifact proof in the frozen mode, including the frozen source and comparison attachments when applicable.
8. Explicit Amp-origin `consume` establishing `delivered`.
9. Independent verification or rejection of every candidate.
10. Pre/post Tycho GitHub snapshots proving no Tycho-phase mutation.
11. Amp-only reconciliation of at most one owned PENDING review, including per-write PR-head equality and canonical snapshot checks.
12. Separate `acknowledge` after handling. Retain acknowledge output as cleanup evidence; `show` cannot supply `custody_cleanup` status.
13. If cleanup is `pending`, retain each identical same-directory replay result. Final `show` records only terminal state and append-only event order.
14. Map the six PR #11886 gaps below and record the cycle for owner assessment.

**Complete when:** every item has exact evidence or the run is explicitly classified as ordinary-use-only, not field evidence.
